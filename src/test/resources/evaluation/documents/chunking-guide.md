# 文档分块与引用定位

## 分块参数

演示基线把单个分块上限设为 512 tokens，相邻分块重叠 64 tokens。重叠用于保留跨边界语义，但过大重叠会增加向量数量和检索噪声。

## 稳定标识

每个向量使用知识空间、文档、版本、分块序号和内容哈希生成确定性 ID。重复执行同一批次不会产生随机向量标识。

## 引用字段

可信引用至少包含 documentId、chunkId 和 chunkIndex；解析器能够取得信息时还应包含 pageNumber 与 sectionTitle。引用跳转必须按 chunkId 精确定位，而不是按文件名模糊匹配。

## 内容哈希

上传内容使用 SHA-256 计算哈希。相同知识空间中的相同内容会被去重；同名文件内容变化时创建新版本，成功激活后旧版本标记为 STALE。
