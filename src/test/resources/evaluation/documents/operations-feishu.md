# 运行、会话与飞书同步

## 运行端口

本项目应用验收端口固定为 19050，Milvus gRPC 验收端口为 19055。通用基础设施复用 shared-infra：MySQL、Redis、Chroma 的宿主回环端口分别为 13306、16379、18000；它们的容器内端口保持 3306、6379、8000。应用容器内端口保持 8080。

## 会话与限流

Redis 使用 Lua 原子追加一轮用户和助手消息，同时裁剪历史并刷新 TTL，避免多实例读改写覆盖。限流依赖不可用时接口返回 HTTP 503；超过额度时返回 HTTP 429 和 Retry-After。

## 飞书增量同步

飞书同步必须完整枚举全部分页和子节点，并使用分布式锁避免多实例并发。429、5xx 与超时采用有限重试，运行结果保存同步报告。

## 防误删

远端节点缺失不能立即删除本地资料。只有连续两次完整且无内容失败的同步都确认缺失，且候选数量和比例未超过阈值时才允许删除。分页失败、零节点异常、权限收缩或内容读取失败都会阻断删除阶段。
