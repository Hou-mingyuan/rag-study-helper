# 向量存储与索引维护

## 三种后端

InMemory 是进程内临时存储，适合零依赖演示和单元测试，进程重启后必须从 MySQL 当前分块重建。Chroma 提供轻量持久化，适合单机学习环境。Milvus 面向更大规模和分布式部署。

## 检索

查询与文档都转换为 Embedding 向量，使用余弦相似度计算接近程度。系统先取 top 20 候选，再由 Rerank 保留 top 5。

## 维度保护

向量集合元数据记录 embedding 模型名称、维度和 schema 版本。配置维度与现有集合不一致时必须拒绝启动写入；操作者应选择新集合并执行安全重建，不能覆盖旧集合。

## 数据真源

MySQL 是活跃文档版本和分块状态的真源。向量库是可重建索引；查询命中后仍需回到 MySQL 丢弃过期版本、已删除文档和跨知识空间结果。
