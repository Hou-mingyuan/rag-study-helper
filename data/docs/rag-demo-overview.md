# RAG 检索增强生成 — 演示文档

> 本文件为 **Mock 零密钥演示** 内置知识库样例，启动时自动扫描入库。

## 什么是 RAG

RAG（Retrieval-Augmented Generation，检索增强生成）在回答用户问题前，先从知识库中**检索**相关文档片段，再把这些片段作为上下文交给大模型**生成**答案。

典型链路：

1. **文档入库**：上传 PDF/Markdown 等，切分为 chunk，调用 Embedding 模型向量化。
2. **向量检索**：用户提问同样向量化，在向量库中找 top-K 最相似片段。
3. **重排序 Rerank**：对召回结果二次排序，保留最相关的 3–5 条。
4. **Prompt 组装**：把片段 + 用户问题拼成 prompt，调用 Chat 模型流式输出。

## 核心概念

| 概念 | 说明 |
| --- | --- |
| Embedding | 把文本映射为稠密向量，语义相近的文本向量距离更近 |
| 向量数据库 | 存储 chunk 向量，支持近似最近邻搜索（ANN） |
| 分块 Chunk | 长文档按段落或 token 切分，避免超出模型上下文 |
| 查询改写 | 多轮对话中将「它有什么好处」改写成带上下文的完整问句 |

## 演示问答示例

- 「RAG 是什么」→ 应命中本文「什么是 RAG」段落
- 「Embedding 用来做什么」→ 应命中「核心概念」表格
- 「向量检索的流程有哪些步骤」→ 应命中「典型链路」
