# 查询改写与多轮对话 — 演示文档

## 为什么需要查询改写

在多轮 RAG 对话中，用户常使用指代词，例如：

- 第一轮：「RAG 有哪些核心步骤？」
- 第二轮：「**它**有什么好处？」

若直接用「它有什么好处」做向量检索，Embedding 无法理解「它」指 RAG，容易召回错误文档。

## 改写策略

QueryRewriteService 会结合最近若干轮历史，把短问句改写成自包含的检索 query，例如：

- 输入：「它有什么好处」+ 历史含 RAG
- 改写：「RAG 有什么好处」

Mock Chat 在检测到「查询改写助手」prompt 时会做简单规则改写，便于离线演示。

## Web 上传入库

除启动时扫描 `data/docs/` 外，可在 Web UI **知识库** 面板上传 `.md` / `.txt` / `.pdf` 等文件：

1. 选择文件 → 上传
2. 后端解析、分块、向量化并写入向量库
3. 在对话区提问，即可基于新文档回答

演示路线：先确认内置文档已入库，再上传自定义 markdown，追问文档中的专有名词。
